# Contributing

Contributions should keep this repository focused on safe, authorized browser-automation education.

## Guidelines

- Read the README and security policy before changing automation behavior.
- Keep credentials, cookies, personal data, and browser profiles out of Git.
- Prefer stable, semantic selectors and explicit waits over absolute XPaths and arbitrary sleeps.
- Do not add code intended to bypass CAPTCHA, authentication, rate limits, or purchase safeguards.
- Document browser, driver, Python, and Selenium compatibility for behavior changes.

## Validation

Run syntax checks locally and, when authorized, test against a controlled page or mock fixture. Do not run live shopping actions against accounts or place orders. Explain manual checks and known site-dependent limitations in pull requests.
