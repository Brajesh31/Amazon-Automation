## Reporting an issue

Include the operating system and architecture, Python and Selenium versions, Chrome and driver versions, command used, and a sanitized traceback. Mention whether the issue reproduces with a local mock.

Do not attach browser profiles, cookies, credentials, account data, payment information or unredacted screenshots.

## Scope

This project does not guarantee that external website selectors remain valid. Stop automation when the target blocks or challenges the browser.
