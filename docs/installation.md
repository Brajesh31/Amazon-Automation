# Installation

1. Install Python 3.10+.
2. Install Google Chrome.
3. Create and activate a virtual environment.
4. Install Selenium with `python -m pip install selenium`.
5. Install a ChromeDriver compatible with the installed Chrome version, or use Selenium Manager.
6. Update the driver configuration in `main.py` before running.

Keep the driver binary executable and never put credentials or a persistent personal browser profile in the repository.
